An entry for make.fun's [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty: one error message, at most 120 characters, that a kitchen toaster shows its owner — after four toastings, the bagel is now legally a cracker.

`main.py` (Python 3, stdlib only) writes the message to `/output/entry.txt`, deterministically, via a temp file plus rename with mode 644.
